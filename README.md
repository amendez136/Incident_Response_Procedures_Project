# Incident_Response_Procedures_Project
Cybersecurity incident response case study involving credential exposure, unauthorized access investigation, risk assessment, and Critical Incident Response (CIR) procedures.

## Overview
This project demonstrates the application of cybersecurity Incident Response (IR) procedures through a simulated security incident involving exposed student credentials at XYZ College.

The investigation follows a structured Incident Response process to determine whether a Critical Incident Response (CIR) investigation should be initiated. The project includes incident identification, risk assessment, impact analysis, evidence review, and completion of a CIR Investigation Form.

## Scenario Summary
REN-ISAC notified XYZ College that student credentials were discovered in a publicly accessible credential dump. At approximately the same time, a student reported unauthorized activity and unexplained charges associated with their account.

The incident required an investigation to determine:
- Whether unauthorized access occurred
- What information may have been compromised
- Which users and systems were affected
- The severity of the incident
- Appropriate containment and recovery actions

## Project Objectives
- Analyze a cybersecurity incident using Incident Response procedures and frameworks.
- Identify indicators of compromise (IOCs).
- Assess risks to users and institutional systems.
- Determine whether Critical Incident Response (CIR) procedures should be activated.
- Document investigative findings using a formal CIR report.
- Recommend containment and recovery actions.
